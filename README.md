## 🛠️ Tech Stack & Architecture

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS + Custom CSS Variables & Typography
- **Animation:** Framer Motion (page turns, interactive vinyl, modal transitions)
- **Typography:** Instrument Sans, Instrument Serif, IBM Plex Mono

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/Leoul-Z/Portfolio.git

# Navigate to the directory
cd Portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev

# Run lint checks
npm run lint

# Build for production
npm run build
```
